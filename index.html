Core topics

Choose a language and learn it from basic to advanced.

HTML

Build the structure of every webpage.

HTML gives content meaning. Start with structure, then move into accessibility, forms, SEO, and production-ready page architecture.

Beginner

Build your first pages

  • Understand tags, attributes, headings, paragraphs, and links.
  • Create lists, images, tables, and simple forms.
  • Learn the purpose of <html>, <head>, and <body>.

Intermediate

Write cleaner, semantic markup

  • Use semantic elements like <header>, <main>, and <section>.
  • Improve accessibility with labels, alt text, and landmarks.
  • Organize reusable page sections for blogs, landing pages, and dashboards.

Advanced

Ship real-world content structures

  • Optimize content for SEO, performance, and assistive technologies.
  • Design advanced forms with validation-friendly structure.
  • Plan scalable markup systems that work with modern CSS and JavaScript.
CSS

Style layouts and make websites look professional.

CSS controls presentation. Learn the basics first, then move into layout systems, responsiveness, animations, and polished design systems.

Beginner

Style the basics

  • Learn selectors, colors, spacing, borders, and typography.
  • Practice classes, IDs, and simple hover effects.
  • Understand the box model and how spacing affects layout.

Intermediate

Build responsive layouts

  • Use Flexbox and Grid for modern page sections.
  • Create tablet and mobile layouts with media queries.
  • Organize variables, reusable utilities, and component styling.

Advanced

Create polished UI systems

  • Add transitions, transforms, and layered visual effects.
  • Build theme systems, scalable tokens, and reusable patterns.
  • Refine performance with maintainable selectors and clean architecture.
JavaScript

Add interactivity and logic to modern websites.

JavaScript brings pages to life. Learn syntax first, then master the DOM, APIs, async patterns, and app-level thinking.

Beginner

Learn core programming basics

  • Start with variables, data types, conditions, loops, and functions.
  • Practice arrays, objects, and simple problem solving.
  • Write small scripts that react to button clicks and user input.

Intermediate

Control the browser with confidence

  • Manipulate the DOM to update content dynamically.
  • Use events, forms, local storage, and fetch requests.
  • Break logic into reusable functions and modules.

Advanced

Think like a real-world developer

  • Master async JavaScript with promises and async/await.
  • Handle APIs, state changes, and performance-focused UI updates.
  • Prepare for frameworks by building strong vanilla JavaScript fundamentals.

Study roadmap

A simple path to become confident in each language.

Step 1: Start with the basics

Learn syntax, core tags or rules, and build small exercises until the foundations feel natural.

Step 2: Practice intermediate projects

Create full sections, responsive layouts, and interactive components to turn knowledge into skill.

Step 3: Reach advanced confidence

Focus on accessibility, performance, clean architecture, and real-world project building.
