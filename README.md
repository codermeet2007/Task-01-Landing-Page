# Nexus Studio

**SkillCraft Technology Web Development Internship — Task 01**

## Description
Nexus Studio is a responsive landing page featuring a fixed navbar with dynamic scroll styling, smooth-scroll navigation, scroll-triggered reveal animations, and a validated contact form.

## Features
- Fixed navbar with transparent-to-solid backdrop blur transition on scroll
- Hover animations with center-grow underline effect on nav links
- Hamburger menu for mobile with slide-down full-width navigation
- Hero section with asymmetric layout and CSS animated gradient background blobs
- Work/Portfolio section with 3 hover-lift project cards
- Services section with 4 services in a 2x2 grid
- Contact section with gradient border button and inline social links
- Scroll-triggered fade-in and slide-up animations using IntersectionObserver
- Fully responsive across mobile, tablet, and desktop

## Tech Stack
- HTML
- CSS
- Vanilla JavaScript
